LAB DAILY PIPELINE

实验室日报工作流

「实验室雷达」人机协同内容流水线：机器负责巡视与初稿，黄师傅负责三次关键决策。每天一篇口播脚本 + 一篇公众号文章，母体是「实验室」这个母题，落点是「实验室前线 / 实验室手记 / 实验室内参」三条产品线。

一、一天的四个节点

06:00 晨间巡视机器自动
执行：定时自动化「实验室雷达·每日晨间巡视」（已启用）｜黄师傅动作：无，睡醒即可
自动扫描五层信息源（顶级期刊 → 高校官网 → 科技媒体 → 科学家/投资人社媒 → 中文自媒体），只保留「能反推到具体实验室」的消息。
产出《实验室雷达早报》：今日雷达 5–8 条 + 3 个候选选题（含建议栏目、人文角度、工作量）+ 1 句主编推荐。
存盘：实验室雷达/YYYY-MM-DD-早报.md
08:00 第一次互动：定选题黄师傅决策 · 约 3 分钟
输入：早报 3 个候选｜决策：选 1 个（或推翻另给方向）｜机器随后：系统收集资料 → 撰写提纲
口令 A（三选一）：「选题 2，开做」　／　口令 B（自定方向）：「今天做 XX 实验室的 XX，开做」
你确认后，我立即执行：①围绕选题做深度资料收集（论文原文、实验室官网、PI 背景、相关历史脉络、产业转化情况）②撰写文章提纲（结构、小标题、核心故事线、预计字数）③同步列出口播脚本的分镜思路。
产出存盘：实验室雷达/YYYY-MM-DD-提纲.md，12 点前就绪等你确认。
12:00 第二次互动：定核心思路黄师傅决策 · 约 5 分钟
输入：提纲 + 分镜思路｜决策：确认 / 调整核心思路｜机器随后：写口播脚本 + 写公号文章
口令 C：「提纲 OK，开写」　／　口令 D：「第 3 部分换成 XX 角度，其他 OK，开写」
你确认后，我并行产出两件半成品：
①口播脚本（四段式：开场提问 → 现场/影像 → 访谈/讲述 → 人文评论；标景别与时长，2–5 分钟体量）
②公众号文章（深度图文，2000–3500 字，手记口吻：多故事细节、少空话大道理）
存盘：实验室雷达/YYYY-MM-DD-口播脚本.md 与 YYYY-MM-DD-公号文章.md，18 点前就绪。
18:00 第三次互动：定稿黄师傅决策 · 约 5 分钟
输入：两件半成品｜决策：通过 / 改｜机器随后：终稿 + 配图建议 + 分发清单
口令 E：「定稿」　／　口令 F：「口播第二段重写，文章结尾收一收，再给我看」
定稿后我交付：①终稿文件 ②配图/封面建议（含外包设计师需求说明）③分发清单（公众号/视频号/小红书/抖音的标题与简介适配版本）④归档到素材库，供「实验室内参」周度汇编复用。

二、信息源清单（6 点巡视固定扫描）

层级信息源扫描重点
顶级期刊Nature / Science / Cell 及子刊新闻页重磅论文、官方新闻稿
高校与机构官网MIT / Stanford / Harvard / Caltech；DeepMind / OpenAI / Anthropic 博客；清华 / 北大 / 中科院 / 之江实验室 / 北京·上海 AI 实验室实验室成果披露、PI 动态
科技媒体MIT Technology Review、量子位、机器之心、DeepTech深科技、36氪、极客公园、新智元24h 内的实验室报道
人物社媒全球科学家、科技企业家、创业者、头部投资人公开发言24–48h 重要表态与争论
中文自媒体科技、商业资讯类账号被多家转载的热点，验证国内传播度
入选铁律：每条消息必须能落到一个具体的实验室 / 研究团队 / PI。落不到实验室的纯产品、融资、政策新闻一律不进早报——这条流水线只生产「实验室」母题的选题。

三、文件结构（流水线沉淀即素材库）

实验室雷达/ ├── YYYY-MM-DD-早报.md ← 6:00 机器产出 ├── YYYY-MM-DD-提纲.md ← 8:00 你确认后产出 ├── YYYY-MM-DD-口播脚本.md ← 12:00 你确认后产出 ├── YYYY-MM-DD-公号文章.md ← 12:00 你确认后产出 ├── YYYY-MM-DD-终稿/ ← 18:00 定稿归档（含分发版本） └── 选题池.md ← 未被选中的好选题滚动留存

每天攒下的早报与终稿，就是「实验室内参」周报的原料、B2B 提案的案例库——流水线本身就是资产。

四、质量闸门（每道都得过）

事实闸：所有成果表述必须有信息源支撑，链接随文留存；拿不准的一律标注「待核实」，不硬写。
口吻闸：多故事、细节、亲身经历，少空话大道理；可引文化名人典故但必须具体；全文零「从来 / 从来不是 / 从来不」类表述；不引用《顺》书内容。
母体闸：每篇必须回扣「实验室」母题——现场、人物、成果、转化，至少占其一。
定稿闸：AI 起草，黄师傅定稿。任何一篇未经你 18:00 确认的内容，不进入发布流程。

五、节奏兜底与周复盘

  • 你某天没空互动：流水线自动降级为「只出早报 + 存选题池」，不硬产半成品，避免垃圾积压。
  • 选题池机制：每天 3 个候选里没被选中的，自动滚入「选题池.md」，周日统一过一遍，好选题不浪费。
  • 周日复盘（建议每周日 20:00，10 分钟）：看本周 7 份早报 + 产出成稿数，对我说一句「本周复盘」，我出周报：选题命中率、成稿率、哪类实验室题材反馈好、下周栏目侧重建议。
  • 与整体节奏的衔接：「前线」走短视频平台（图灵的金枪鱼账号试验），「手记」走公众号主品牌，「内参」按月汇编服务 B2B（红波线 / 动量 / 原科瑞控）。
