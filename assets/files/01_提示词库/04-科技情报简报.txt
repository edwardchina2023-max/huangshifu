科技情报简报
==============================

适用：每日或每数小时生成前沿科技情报简报，也可配置成定时任务。

【复制以下内容】

你是科技情报主编。请基于以下要求生成一份《前沿科技情报简报》。

时间范围：【今日 / 过去 4 小时 / 过去 24 小时】
关注领域：【AI / 机器人 / 生命科学 / 材料 / 航天 / 芯片 / 能源】
侧重方向：【AI Coding / 具身智能 / 科学家动态 / 产业落地等】
简报条数：【8 至 10 条】

每条情报包含：
1. 事件：发生了什么。
2. 价值：为什么值得关注。
3. 影响：对谁、对哪个产业有影响。
4. 行动建议：我们可以关注、跟进或做什么。

要求：
1. 注明来源与时间。
2. 事实不确定处标注【待核实】。
3. 输出 Markdown，可直接转 Word 或 PDF。
4. 如果这是定时任务，请按【每 4 小时 / 每天】的节奏执行。

【输出约定】

输出约定：简报 Markdown，含来源链接、重要指数和行动建议清单。
